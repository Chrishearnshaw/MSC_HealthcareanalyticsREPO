# Colab Auto Connect Demo

This is a tiny example notebook project you can use to practise connecting a local notebook editor to Google Colab.

## Open It

Open `colab_auto_connect_demo.ipynb` in the notebook editor.

Then choose:

```text
Kernel > Colab > Auto Connect
```

After it connects, run the cells from top to bottom.

## What The Notebook Does

- Prints the Python version.
- Creates a small sample data set.
- Makes a simple chart.
- Saves a tiny output file called `demo-output.txt`.

If the `Kernel > Colab` menu is missing, the notebook editor or extension you are using may not have Colab integration enabled.
