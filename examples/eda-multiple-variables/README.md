# EDA: Multiple Variables

Exploratory data analysis lab for exploring the distribution of **multiple** variables,
adapted from a Google Colab notebook.

Uses the [World Happiness Report](https://raw.githubusercontent.com/thousandoaks/Maths4DS101/main/data/world-happiness-report.csv)
dataset (loaded directly over HTTP) and covers:

1. Correlation matrices (`pandas`)
2. Heatmaps (`seaborn`)
3. Scatter plots
4. Box plots
5. Violin plots

## Requirements

```
pip install pandas seaborn matplotlib numpy scipy
```

## Run

Open `eda_multiple_variables.ipynb` and run the cells top to bottom. An internet
connection is required for the first data-loading cell.
